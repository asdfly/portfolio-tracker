## 七、台账治理规则（建议固化）

1. **分区法**：待执行项区只放「需改代码/配置/口径决策」的条目；运行日志（反思/小结/巡检快照）另立 `运行日志` 区或直接落 `logs/`。
2. **三元组强制**：每条必须含 `动作 + 落点文件 + 验收判据`，缺一不得入待执行区。
3. **一因一单**：同一根因只建一张工单，其余条目改为「承接 #编号」，不再独立成条。
4. **30 天熔断**：入区满 30 天仍无路径 ⇒ 强制二选一——转「已知限制」，或明确降级理由。禁止滞留。
5. **销账即闭**：代码落地当轮立即勾选并移入历史区；不得靠人肉记忆（本次已发现 1 例滞留 14 天）。
6. **月度 triage**：每月首个交易日按本报告模板重跑一次，输出「簇数量 / 真待办数 / 新增 / 销账」四指标，监控台账是否重新劣化。
