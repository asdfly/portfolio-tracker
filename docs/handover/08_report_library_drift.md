## 一、复现口径（可重跑）

**取 HTML 页头「总市值」**（不能用 `总市值` + 任意字符去抓，`<div class="v" style="color:#1a73e8">`
里的 `#1a73e8` 含数字，会被误命中成 `1.0`）：

```python
VAL_RE = re.compile(r'总市值</div><div class="v"[^>]*>\s*[¥￥]?\s*([0-9][0-9,]*(?:\.[0-9]+)?)')
```

**取页头日期 / 生成时刻**（`enhanced_report` 的头部结构）：

```html
<h1>📊 投资组合日报</h1><p>2026年09月14日 周一</p>
<p style='...'>数据来源: 新浪财经 / 东方财富 | 更新时间: 15:37:17</p>
```

**取库内基准**：

```sql
SELECT date, total_value FROM portfolio_summary ORDER BY date;   -- 3477 行，max = 2026-09-14
```

**判定阈值**：`abs(HTML − 库值) < 0.51` 记 `MATCH`。理由：HTML 展示为整数千分位，库内为 2 位小数，
真实误差只来自四舍五入。实测 `MATCH` 组的最大偏差恰为 `±0.50`。

**交叉验证**：`enhanced_report_20260914.html` 页头 `933,892` ↔ 改写前备份
`data/backups/portfolio_PRE_P05_20260915_1028.db` 的 09-14 `total_value = 933,891.5` ⇒ 一致。
这证明 `DIFFER` 组捕获的是**改写前的旧世界**，而不是抽取错误。
